# Language coverage plan

Status: planned, not started (2026-10-01).

Two goals:

1. Filter by every LibriVox source language, whatever the app's interface language.
2. Add four interface languages: Finnish, Modern Greek, Traditional Chinese and English (UK).

Latin and Ancient Greek stay content-only. Their audiobooks are fully searchable, but there is no Latin or Ancient Greek interface.

## Baseline (archive.org, 2026-10-01)

A full pull of `collection:librivoxaudio` returned 21,821 items. They carry 57 distinct `language` values.

**Covered by the current 15-entry filter:** English (19,067 items), German (845 `deu` + 2 `ger`), Spanish (560), French (275 `fre` + 40 `fra` + 1 `French`), Dutch (209 + 1 `dut`), Portuguese (107), Italian (88), Russian (75), Ancient Greek (45 `grc`), Japanese (37), Polish (31), Chinese (25 `zho` + 1 `chi`), Hebrew (24), Latin (16) and Finnish (16).

## Part 1 — Filter by every LibriVox source language

### What's wrong today

- **Hard-coded list.** `Voxglass/Core/Catalog/LibriVoxLanguage.swift` defines a 15-entry `all` list. These all read from it:
  - `SettingsView` and `OnboardingPreferencesView` (the pickers);
  - `MacViews`;
  - `deviceDefaultSelection` (a hard-coded `switch`);
  - `InternetArchiveModels.displayLanguage(for:)`;
  - `CollectionCoverStore` and `HomeRecommendationStore`, through `clause(for:)`.
- **Greek mapping.** "Greek" queries `grc` and `gre`, so Modern Greek (`ell`) is never searched.
- **Display names.** "German" is special-cased in code. The other names depend on Foundation resolving 3-letter codes such as `fre` and `zho`; when it can't, the name stays in English.
- **Duplicated list.** `Tools/CuratedLists/main.swift` keeps its own copy of the token list.

### Steps

1. **Generate the language table.**
   - Add `Tools/LibriVoxLanguages` (`swift run librivox-languages`), modelled on `Tools/CollectionCounts`.
   - It pages through the archive.org scrape API for `collection:librivoxaudio` and writes `Voxglass/Core/Resources/librivox-languages.json`.
   - Each entry holds:
     - `id`: the canonical ISO 639-3 code;
     - `tokens`: every `language` value seen for it, merged across variants (`deu`/`ger`/`German`, `fra`/`fre`/`French`, `nld`/`dut`, `zho`/`chi`, `spa`/`es`, `eng`/`English`, …);
     - `bcp47`: a 2-letter or language-script tag for display-name lookup, where one exists;
     - `count`: the item count;
     - a `generatedAt` date stamp for the file.
   - `LibriVoxLanguage.all` loads from the bundled file.
   - `Tools/CuratedLists` reads the same file instead of mirroring it.
   - CI never calls the network. The file is regenerated by hand, like `CollectionBundledCounts`.

2. **Edge cases.**
   - **Greek:** split it into separate entries:
     - Modern Greek (`ell`);
     - Ancient Greek (`grc`).

     Sample real items tagged `gre` and plain `Greek` before deciding which entry each tag belongs to.
   - **Multilingual (`mul`):** a selectable option.
   - **Untagged items:** an "Unspecified" option, so selecting every language still reaches them.
   - **Historical forms:** keep their own entries — Middle English (`enm`), Old English (`ang`) and Church Slavonic (`chu`).

3. **Display names in any interface language.**
   - Resolve names with `Locale.current.localizedString(forLanguageCode:)` using the `bcp47` tag (`el`, `zh`, `fi`, …).
   - Where Foundation has no name, use a String Catalog key so the name gets translated: Church Slavonic, Old English, Middle English, "Multilingual" and "Unspecified".
   - Remove the "German" special case.
   - Sort by the localized name with `localizedStandardCompare`.

4. **Picker redesign** — iPhone Settings, Onboarding and the Mac app share one component.
   - **Popular section:** the top 10 languages by item count, plus the device language.
   - **All languages section:** A–Z by localized name. Each row shows its item count.
   - **Search field:** filters by the localized name, the English name and the code.
   - An empty selection still means "all languages".

5. **Query building.**
   - Each selected language sends every one of its tokens to archive.org.
   - Measure the URL length with all languages selected.
   - If every language is selected, send no language clause at all.

6. **Defaults and stored settings.**
   - Replace the `switch` in `deviceDefaultSelection` with a lookup through the table, so every device language that has LibriVox content works.
     - `el` maps to `ell` (Modern Greek), not `grc`.
     - `en-GB` maps to `eng`.
     - `zh-Hant` maps to `zho`.
   - Existing values in `voxglass.selectedLanguages` keep working. A stored `grc` stays Ancient Greek.

7. **Book detail screens.** `displayLanguage(for:)` resolves through the table, so every language gets a proper label.

8. **Tests.**
   - The table covers every token in the generated snapshot, with no duplicates and no token claimed by two languages.
   - `clause(for:)` produces the right query for multi-token languages, and none when everything is selected.
   - Modern and Ancient Greek stay separate.
   - Every entry has a non-empty display name in all 16 interface languages.
   - `deviceDefaultSelection` maps each interface language correctly, plus unknown languages and `en-GB`.
   - Stored selections from before the change still load.

## Part 2 — Add Finnish, Modern Greek, Traditional Chinese and English (UK)

1. **Project setup.**
   - Add `fi`, `el`, `zh-Hant` and `en-GB` to `knownRegions` in `project.yml`, then regenerate with XcodeGen.
   - Add the same four to `supportedLanguages` in `VoxglassTests/LocalizationCatalogTests.swift`.
   - Add them to `scripts/audit_app_store_release.sh` if it lists locales.

2. **Translations.** About 1,720 keys across the catalogs, plus the new language-name keys from Part 1:

   | Catalog | Keys |
   |---|---|
   | `Voxglass/Resources/Localizable.xcstrings` | 1,172 |
   | `Voxglass/Core/Resources/Localizable.xcstrings` | 377 |
   | `VoxglassWatch/Resources/Localizable.xcstrings` | 126 |
   | `VoxglassWidgets/Localizable.xcstrings` | 40 |
   | `Voxglass/Resources/InfoPlist.xcstrings` (microphone prompt) | 1 |
   | `Voxglass/Resources/AppShortcuts.xcstrings` (Siri phrases) | 2 |

   - **Finnish, Greek and Traditional Chinese:** translate with the same dump, validate and merge tooling used for the other apps. Mark everything `needs_review` for a native-speaker pass.
   - **English (UK):** generate by converting US spellings to British, then check by hand.
   - **Plurals:** Finnish, Greek and English (UK) need `one`/`other`; Traditional Chinese needs `other` only.
   - **Siri phrases:** keep the `stringSet` form, with every phrase translated.

3. **Tone and conventions.**
   - **Greek:** formal forms (εσείς), matching Voxglass's formal German (Sie).
   - **Finnish:** neutral register, as in Apple's own Finnish strings.
   - **Traditional Chinese:** Taiwan terminology and punctuation.

4. **Fonts and layout.**
   - **Glyph coverage:** confirm the `voxFont` faces cover Greek and Traditional Chinese characters, or fall back to the system font cleanly.
   - **Text length:** Greek and Finnish run long, so check truncation on the player, mini-player, CarPlay, the Watch, widgets and the Live Activity.

5. **Siri caveat.** Siri does not support Greek, so the Greek App Shortcut phrases may never trigger. Finnish and Traditional Chinese are supported. Localize all four regardless and record the caveat in the README.

6. **About screen.** `shippedLanguageNames` reads the bundle's localizations, so the count and list should update to 16 on their own. Confirm this.

## Order and verification

1. Part 1. It adds new user-facing strings.
2. Part 2. Translate all strings, old and new, in one pass.
3. Part 3, the README.
4. Run the package and app tests, the localization guard, and a full iOS build.
5. Push, then watch CI through the TestFlight upload.
