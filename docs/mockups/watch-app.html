Voxglass Apple Watch - normative implementation mockups

These screens are an implementation handoff for the standalone watch app. They include unhappy fetch states, fixed point budgets, and the accessibility identifiers expected by the local smoke test. Baseline panels are drawn at true 45 mm logical size, 198 × 242 pt, then shown at 1.5x.

Layout Doctrine

  • Browsable roots use watch-native lists.
  • No nested scroll/geometry layout for simple screens.
  • Transport and action controls keep 44 pt tap targets.
  • Long sync/status text splits into stacked rows.
  • Async screens always show loading, empty, or error state.

Fixed Watch Sizes

Minimum162 × 197Fit gate for smallest supported simulator.
Baseline198 × 242All mockup watches on this page.
Large205 × 251Ultra-class check; use larger if local Xcode offers it.
