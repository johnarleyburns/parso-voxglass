Unified Book Page — Now Playing ∪ Book Details

One screen replaces both NowPlayingView and BookDetailView. Same layout in both states; only the transport block changes. Author and narrator are always visible under the title. The description is clamped to a single line and expands from a Show more control that sits immediately above the Chapters card. Every former full-width button (Share, Playlist, Favorite, Offline) is now a 40 pt icon; AirPlay joins the row; the rest live behind the ⋯ overflow.

Once the cover scrolls away, the toolbar collapses into a compact title + play/pause bar so transport is never more than one tap away.
Icon row order is fixed: Speed · Sleep · Bookmark · Favorite · Offline · AirPlay · ⋯. Under accessibility text sizes the row degrades with ViewThatFits to Speed · Favorite · AirPlay · ⋯ and the dropped controls move into the overflow, so nothing ever shrinks below a 44 pt hit target.
