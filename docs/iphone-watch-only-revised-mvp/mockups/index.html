Revised mockup set for SPEC.md. Every screen lives inside the existing Voxglass app, entered from the Narration tab — there is no separate Studio app. Numbering matches the superseded set in docs/iphone-watch-only-mvp/mockups/ so the two can be diffed 1:1.

Design compliance

Tokens are transcribed from the app, not invented: Voxglass/DesignSystem/VoxglassTheme.swift and AdaptiveGlass.swift. Use the GLASS / SOLID toggle at the top-right of any screen to see the Reduce Transparency fallback that AdaptiveGlass actually renders — a design that only works with blur is not compliant.

Reading the identifiers

HTML id attributes on interactive elements are the .accessibilityIdentifier values the implementation must use. Identifiers already shipping (record.*, player.*, paragraphList.*, queueBuilder.*, note.*, import.*) are preserved deliberately — the UI smoke tests key on them.
