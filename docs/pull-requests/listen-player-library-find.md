# Simplify listening screens, isolate Find sources, and dismiss the watch connection toast

Listen, Find, and My Books now use the same three semantic Dynamic Type sizes: large title for page titles, subheadline for search fields/source controls/section headings, and footnote for all card text. Book titles, authors, narrators, ownership/progress/watch metadata, Gutenberg credits, and collection-card text use the same card size; weights and colors retain hierarchy. Shared components opt in at these screen call sites, preserving their default styling elsewhere. Search fields and collection cards use minimum heights, Listen shelf text budgets scale with footnote, and My Books' list-height allowance scales with Dynamic Type. Uniform card text does not shrink to fit.

Listen shelf cards now reserve three title lines and grow with Dynamic Type. Continue Listening uses the same title and author typography, drops the Resume pill, and uses a chevron to resume playback and open Now Playing. The handoff also handles a previously selected session whose book ID does not change.

Now Playing keeps the cover, credits, current chapter, scrubber, and transport controls. Glass chapter and hamburger buttons occupy the upper left and right. The chapter button opens the full chapter page; the player remains a swipe-down sheet without a root back button. Playback speed, sleep timer, bookmarks, watch controls, AirPlay, and AI voice selection live in Book Details. Library status, chapter count, offline availability, public-domain information, and the summary also appear there. AI narration uses the normal narrator-credit location and footnote style with “Read by AI ‘<voice>’”; the source-credit row is removed.

My Books has one glass option row: In Progress, Finished, and On My Watch. Books sort by most recent playback time descending, across the full listening history. Unplayed books follow played books. Manual ordering and conflicting sort menu choices are removed.

Find now offers exactly LibriVox, LibriVox Collections, and Gutenberg Read by AI, defaulting to LibriVox. Each submission searches only the selected catalog; the menu’s All option still means all search fields within that catalog. Collections require a selected collection and never trigger Gutenberg. Switching sources cancels requests, clears the previous source’s results, and invalidates late successes and errors. Collection browsing uses the same source selection, avoiding contradictory navigation state. The All/Title/Author/Narrator row is removed from beneath the text field. Those four mutually exclusive choices now appear directly in the top-right filter menu, above the independent Single narrator toggle. The default remains All selected and Single narrator off.

The Apple Watch connected toast now expires after three seconds even when WatchConnectivity connects before RootView appears. The old onChange-only timer missed that initial value. A view-owned task schedules expiry on appearance and value changes, cancels when replaced or removed, and checks cancellation before dismissing. The persistent connection status remains available in Settings.

Gutenberg analysis found both service availability problems and parser defects. On November 16, 2026, the primary endpoint returned HTTP 503 and an explicit maintenance page; Gutendex timed out from this environment. The parser now bounds each result to its own list item, preserving anonymous books instead of consuming the next result's author. Changed result markup triggers the fallback; only explicit empty-result text counts as a successful empty search. The app cannot repair an upstream outage.

- Twelve new localized strings cover all 16 existing locales with translated state and matching format placeholders; all previous catalog entries are preserved.
- `git diff --check`, Swift 6/release-input audits, and the full fast automation/wiring guard suite pass.
