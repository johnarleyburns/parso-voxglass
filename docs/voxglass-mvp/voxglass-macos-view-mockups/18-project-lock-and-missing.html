Editing the same project from two Macs at once — especially through iCloud Drive or Dropbox — can lose recordings. Voxglass cannot tell whether the other Mac is still using it.

If that Mac is asleep or was force-quit, opening anyway is safe. If it is actively recording, quit Voxglass there first.

Rule: Open Anyway is styled as the destructive action and is never the default. SQLite WAL tolerates the situation technically; the warning exists because the audio files do not. Identifiers: lock.openAnyway · lock.cancel · lock.reveal.
