Mac + iPad Universal MVP

Mockup set for SPEC.md, a delta over the revised iPhone + Watch MVP. Three platforms, one app record, one bundle id, one Universal Purchase. The iPhone and Watch mockups are not superseded — they remain the contract for those surfaces and for iPad in compact width. This set adds only what is new: the Mac window, the iPad in regular width, and the two-writer conflict surface.

Design compliance

This set defines no tokens of its own. style.css imports the revised set's stylesheet, which transcribes the app's own VoxglassTheme.swift and AdaptiveGlass.swift, and adds only the two device frames and the components those surfaces introduce. Use the GLASS / SOLID toggle at the top-right of any screen to see the Reduce Transparency fallback AdaptiveGlass actually renders on every platform — a design that only works with blur is not compliant.

Reading the identifiers

HTML id attributes on interactive elements are the .accessibilityIdentifier values the implementation must use. Identifiers already shipping on iOS — record.*, player.*, paragraphList.*, queueBuilder.*, note.*, import.*, export.*, review.*, script.*, newProject.*, settings.*, validation.* — are reused on Mac and iPad wherever the control means the same thing. New prefixes this set introduces: library.*, batch.*, conflict.*, shortcut.*, sidebar.*, queue.*, presence.*, window.*.

No identifier names a device. The same control has the same id on Mac and iPad — record.recordNext is record.recordNext everywhere — because an identifier that encodes the platform makes a shared control look like two controls to the audit test and to VoiceOver review.

AccessibilityAuditTests currently parses only docs/iphone-watch-only-revised-mvp/mockups. Stage U0 extends it to this directory. Until that lands, these pages are a design contract but not yet a test-enforced one — which is exactly why extending the test is a U0 task and not an afterthought.

What this set does not contain

Any screen labelled “Voxglass Studio” — the Mac app is Voxglass, same bundle id, same app record. Any “Record on Mac” / “Continue on Mac” handoff — retired by N-1 and now banned by gate G-U1; the Mac is an option, never a prerequisite. Any Mac↔Watch surface (D-U4). Any production CarPlay entry point (M-5).
