mac-02 · Script editor (§10) The revised spec deliberately refused a dense multi-pane editor on the phone — “a phone-shaped editor, not a dense multi-pane one”. A Mac affords exactly what the phone could not: chapter outline, paragraph list, and inspector all visible at once. The Core operations underneath are identical — ParagraphSplitter, TextDriftDetector, the same debounce — so the two editors cannot diverge in behaviour, only in density.
